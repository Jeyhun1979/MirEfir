# Контракт поведения MirEfir

Источник правды. Настройки пользователя (`%AppData%\MirEfir`) **не удалять**. Старый Chromium-код из репозитория убран (1.0.25), эталон поведения — этот файл и нативный код. Документ дублирует сценарии, не код. Полный список пунктов меню, вкладок и каждого тумблера/кнопки: `docs/menu-and-settings.md`. План этапов Windows+Android: `docs/native-port-plan.md`.

Одно управление, разные кнопки. **Windows — клавиатура:** Enter / Return / NumpadEnter = ОК, Esc = Назад, стрелки = влево/вправо/вверх/вниз, плюс буквы и F2 как в таблице. **Android — пульт или кнопки приставки** с теми же действиями (ОК, Назад, стрелки). Мышь и гиромышь: клик = ОК по пункту. Не делать «только пульт»: на Windows без клавиатуры приложение неполноценно.

## Куда идём

- Цель: нативные клиенты **Windows и Android**, со **своим** сценарием (не копия чужого приложения). Linux пока не делаем.
- Скорость и стабильность как у приставочных плееров: эфир сразу, оболочка не мешает картинке, память не раздувается.
- Пока нативных клиентов нет — развиваем текущее приложение. Новый код **рядом в своей папке** (`native/windows`, потом `native/android`), не вперемешку с `src/` и `electron/`. Старые файлы **не удалять**, пока новая программа не повторит сценарии и не заработает как надо.

Как не путать старое и новое:
1. Исходники: две полки. Старая оболочка — `src/` + `electron/`. Новая — `native/…`. Не смешивать в одном файле.
2. Пока пишем и проверяем натив: не запускать одновременно `electron:dev` и новую программу (два плеера, одна труба). Для отладки натива — свой профиль (`MirEfir-native`), чтобы не драться с текущим `%AppData%\MirEfir`.
3. Когда натив готов для людей: один Setup с тем же именем, перезаписывает только программу. Профиль `%AppData%\MirEfir` тот же — плейлист не вводить заново. Двух «МирЭфир» в меню Пуск не оставлять.
4. Папку `D:\MirEfir` не трогать без согласия. GitHub Setup/APK сами не выкладывать.

## Закон телепрограммы (обязательно)

Не копить гид бесконечно. Это сознательное отличие: чужие приложения часто качают полный XMLTV и держат его в памяти.

1. Только каналы **текущего плейлиста**. Нет в списке — нет программы в базе.
2. Окно хранения: назад не глубже архива (`archiveDays`, если архив выключен — не хранить прошлое сверх `epgDays`). Вперёд — `epgDays` **полных календарных суток после сегодняшней полуночи** (сегодня в эту семёрку не входит; конец окна — полночь после последнего дня). Не «текущий час + N×24 часа».
3. Интервал `epgUpdateHours` (3 / 6 / 12 / 24 ч): когда срок вышел, докачать **недостающий кусок вперёд** (к примеру, интервал 3 ч → взять новые 3 ч вперёд), а всё, что старше окна архива, **удалить**. Не копить прошлые циклы.
4. Эфир не ждёт EPG. Гид читает базу по каналу, не весь файл в RAM.
5. Источники по цепочке: основной, если пустой/хлам — дополнительный, затем остальные в списке. Берём первый годный файл целиком, не склеиваем и не качаем все сразу. Годный — XMLTV с передачами, хотя бы часть каналов плейлиста нашла программу. Нет гида у части каналов — нормально, не брак. Браковать только пустой ответ, HTML, ошибку и файл без передач. Если все плохие — оставить прежнюю программу и показать ошибку, не висеть. Ссылки в сообщениях не показывать.
6. Перенос на другое устройство: короткий облачный код (сжатый) или JSON-файл. В полях ссылок и кода есть Копировать / Вставить. На пульте: Меню/Опции или удержание ОК на поле — меню Вставить / Копировать / Выделить всё.
7. Нативный клиент: **один** файл базы на диске (не пачка датированных копий, не гигантский JSON в RAM). Обновление гида — дописать новый кусок **в тот же файл** и вычистить устаревшее. Если файл переписывают целиком — сначала временный, потом подмена: старый исчезает сам. Хвосты `epg-old` / `epg (2)` не оставлять.

## Запуск и обновления

- После сохранённого плейлиста сразу полный экран плеера и эфир. Телепрограмма не блокирует картинку.
- Громкость по умолчанию ~35%. Последний канал восстанавливается из сессии.
- Сборки Windows: NSIS Setup, не one-click, можно выбрать папку, ярлык на рабочем столе и в меню Пуск, после установки не запускать само, AppData при удалении не чистить.
- Обновление Windows — **как Cursor, не как мастер-установщик по центру экрана**:
  1. Втихую проверить GitHub через ~4 с (только установленная сборка, не `electron:dev`).
  2. Втихую скачать Setup в фоне, эфир не перекрывать, прогресс не показывать модалкой.
  3. Когда файл готов — слева снизу две маленькие кнопки: **«Обновить»** и **«Позже»**. Смотреть можно дальше.
  4. **Обновить:** закрыть текущее окно → небольшое окно «Установка» с индикатором (splash) → тихая перезапись файлов (`Setup /S`) → снова открыть приложение **с того же места** (последний канал, полный экран, громкость, настройки).
  5. **Позже:** сейчас ничего не ставить, обе кнопки скрыть. Скачанный Setup оставить. Пока сессия жива — поставить его можно из **Настройки → О программе**. После выхода из приложения следующий запуск сам ставит это обновление с тем же маленьким окном прогресса, как по «Обновить».
  6. Канал, громкость и настройки не терять. Setup на GitHub агент сам не выкладывает.
- Почему «не получалось как Cursor»: готовность показывалась большим диалогом по центру («Установить»), а не кнопкой в углу; в режиме разработки проверка вообще не идёт (`not packaged`); без выложенного Setup на GitHub качать нечего.
- Не печатать и не коммитить URL плейлиста, EPG, логины, keystore.

## Кнопки в эфире (полный экран)

| Действие | Поведение |
|---|---|
| ОК / Enter кратко | Открыть нижнее меню плеера (pad). Если pad уже открыт — закрыть. |
| ОК удержать ~550 мс | Меню канала (избранное / переместить). |
| Назад / Esc | Стек `goBack` (см. ниже). С антидребезгом 250 мс. |
| Влево | Телегид (слои дальше). |
| Вправо | Предыдущий канал. |
| Вверх / вниз | Соседний канал. ChannelUp/Down и медиа-клавиши — тоже. |
| Меню / F2 / ContextMenu | Главное меню. Если открыта папка «Избранное» — меню канала. |
| Громкость +/− | Шаг 5%. Mute: `m` / кнопка mute. |
| F1 / Guide | Телегид вкл/выкл. |
| Поиск / `s` | Поиск. Голос / `v` — голосовой поиск. |
| `r` запись, `p` PiP | Честный отказ, если функции нет. |
| Пробел | Избранное текущего канала (настройка `keys.favorite`). |
| `g` | Телегид. |
| Перемотка `,` / `.` | ±30 с, в эфире обычно нет смысла. |

В списке (не полный экран): зоны фокуса группы → каналы → плеер. Вверх/вниз в зоне групп листают группы, иначе каналы. Влево/вправо переключают зону. ОК без полного экрана включает полный экран.

## Стек Назад (`goBack`)

Порядок закрытия, один шаг за нажатие:

1. Сообщение об ошибке  
2. Если уже диалог выхода — **выйти из приложения**  
3. Режим перестановки избранного — отмена  
4. Меню канала  
5. Телегид: `groups` → `categories` → `channels` → закрыть гид  
6. Настройки → главное меню  
7. Любой `uiScreen`: если меню открыто из гида (`resumeGuide`) — вернуть гид на слой папок, иначе закрыть экран  
8. Модалка плейлиста  
9. Pad  
10. Системный fullscreen ОС → выйти из него  
11. Игровой полный экран → диалог «Выйти / Отмена»  
12. Иначе открыть главное меню  

Диалог выхода сам гаснет через 4 с. Назад на этом диалоге = выход. ОК на «Выйти» = выход, на «Отмена» = закрыть диалог.

## Телегид поверх эфира

Слои слева направо: меню приложения ← папки (`groups`) ← категории (`categories`) ← каналы (`channels`) ↔ программа (`programs`) ↔ дни (`days`) ↔ карточка (`detail`).

- Влево с каналов — категории; с категорий — папки; с папок — главное меню с возвратом в гид.  
- Вправо — обратный путь. С каналов вправо — сетка передач.  
- Вверх/вниз в колонке каналов — смена канала (эфир переключается). В передачах/днях — курсор по списку.  
- ОК на канале: кратко — ничего лишнего / удержание — меню канала. Клик по текущей/прошлой передаче — эфир или архив. По будущей — поставить или снять запись по таймеру.  
- Назад на слое каналов закрывает гид, картинка остаётся.

## Главное меню

Пункты сверху вниз: Телевидение, Телепрограмма, Записи, Мультиэкран, Поиск, Микрофон, Плейлисты, История, Настройки, Выход.

- ↑↓ — курсор, ОК — вход.  
- Влево — диалог выхода. Вправо или Назад — `goBack`.  
- Телевидение — закрыть оверлеи, живой список. Телепрограмма — настройки вкладка EPG. Плейлисты — вкладка плейлистов. Настройки — вкладка внешнего вида. Микрофон — тумблер голоса, меню не закрывать. Выход — закрыть приложение.

Настройки закрываются Назад во меню, затем из меню в эфир.

## Pad, часы, картинка

- Pad не сжимает видео, висит над картинкой, чуть выше бегущей строки. Полоса перемотки под кнопками. Подпись канала над pad не нужна.  
- Часы всегда, если включены в настройках (правый верх, не прятать вместе с pad).  
- В полном экране рамка окна не отъедает 16:9. Картинка на всю ширину слота. Меню, гид, pad, часы — **поверх** эфира, не сдвигают и не урезают картинку. Не повторять вчерашние косяки: чёрные полоски от рамки, ужатие под pad, смещение слота. Соотношение сторон — только тумблер Плеер (`auto` / `16:9` / `4:3` / `zoom`), не случайный letterbox оболочки.
- Эфир Windows: нативный mpv, не HLS в Chromium. Гид и меню — поверх картинки, не вместо неё.
- Если устройство не тянет 4K/HEVC — взять лучший доступный поток того же канала (FHD, затем HD, затем SD). Короткое сообщение ~2 с: «Устройство слабое, поэтому переключились на FHD». Не оставлять чёрный экран. На способном железе 4K не трогать.

## Настройки (сохранять и переносить)

Вкладки: Плейлисты, Телепрограмма, Внешний вид, Плеер, Записи, Архив, Родительский контроль, Пульт, Язык, Данные, О программе. Назад из настроек → главное меню.

- Плейлисты: URL/файл, активный, автообновление раз в `playlistUpdateHours`.
- Телепрограмма: основной и запасной источник, сдвиг часов, `epgDays`, автообновление, `epgUpdateHours` 3/6/12/24, описания передач. Закон окна — раздел выше.
- Плеер: автозапуск, помнить громкость, подтверждение выхода, микрофон, декодер auto/hardware/software, буфер 8/15/30/60 с, аспект, внешний плеер, дорожка `ru`/`en`/`orig`.
- Записи: вкл. Rec без папки — спросить **внутренняя память или флешка/диск**, запомнить путь, писать. Путь уже есть — писать сразу. Картинку и звук **не перекодировать** (качество как в эфире). Файл: **MP4** — открывается почти везде. Если поток не лезет в MP4 (редкий звук) — **MKV**, тоже без потери. Сырой `.ts` оставлять только если оба не собрались. Не webm. Не получается писать — причина: нет места, флешка вынута, нет прав, запись выключена. Не из‑за слабого процессора. PiP — второе окошко; на слабом железе может захлебнуться, тогда «недоступно».
- **Запись по таймеру** (Windows и Android одинаково): в гиде на будущей или текущей передаче — «Записать». Появляется в меню Записи. В срок пишет **живой поток этого канала в файл**, картинку на экране не трогает: смотрите другой канал, архив, меню — запись идёт сама. Это как раз когда архива на канале нет: передачу всё равно сохраняем с эфира. Не перекодировать (копия потока, не второй декодер как PiP). Файл MP4, запас MKV. Нет папки — сначала спросить память/флешку. Один таймер за раз. Пока приложение закрыто — таймер хранится; после открытия, если передача ещё идёт, дописать остаток. На Android, когда дойдём: запись может идти свёрнутым (служба), не обещать это на Windows без фонового процесса.
- Архив: вкл, глубина 1/3/5/7/14 дней. Значок ↺ только если в плейлисте канала есть catch-up. Сценарий смотра: в гиде прошедший день → передача → ОК/Enter. Есть архив — включить с того времени (timeshift, как сейчас в `catchup.js`: Xtream, Flussonic, теги плейлиста). Нет / выключен / старше глубины — «Архив недоступен», не чёрный экран. В архиве работают ±30 с и полоса под pad. «Прямой эфир» возвращает в живой поток. В живом эфире вперёд не мотать.
- Внешний вид: тема dark/oled/graphite, акцент blue/orange/teal, прозрачность панелей, шрифт, лого, строк гида 4–9, две строки названия, часы (вкл, место, размер, прозрачность), номера каналов, прогресс в списке.
- Родительский: PIN, закрыть настройки, заблокированные группы.
- Пульт: переназначение клавиш, Назад/CH±/поиск/гид работают сразу.
- Язык: ru/en.
- Данные: облачный код (настройки, избранное, ссылки; локальный файл M3U так не едет) и **файл резервной копии**: Экспорт / Импорт JSON (настройки, плейлист, избранное, гид-ссылки, громкость, сессия). Функция остаётся в нативе.

Громкость (~35% по умолчанию), mute, избранное, история, последний канал, текст/ссылка плейлиста и EPG — в профиле `%AppData%\MirEfir`, **не** в папке программы. Обновление перезаписывает только программу. Профиль не трогать. Удалять и качать заново не нужно.

Первый нативный Setup: то же имя MirEfir, та же папка установки, тот же профиль. Подхватить уже сохранённые плейлист, EPG, настройки, избранное, громкость, последний канал (из `mirefir-config.json` и старого профиля). Пользователь не вводит ссылки заново. Если профиль не прочитался — Импорт резервной копии, не «снести всё».

## Честность функций

Запись и PiP: либо работают, либо явное «недоступно». Не имитировать. На слабом ПК без HEVC HW — программный/частичный HW только для H264.

## Нативный порт

Windows и Android — отдельные оболочки, но **один и тот же сценарий**: всё, что планируем (гид, голос, запись, таймер, обновление, пульт), сразу для обеих платформ, не урезанный Android. Код можно писать сначала Windows, потом Android — поведение одно. Linux не начинать. GitHub Setup не публиковать без явной просьбы.

Интерфейс свой. У приставочных плееров берём **работу эфира**, не экраны. Подробно: `docs/native-engine.md`.

- Windows: mpv, H264 HW где есть. Android: ExoPlayer/Media3 + SurfaceView. Видео не через Chromium, WebView, MSE, hls.js.
- Один экземпляр плеера на сессию. Смена канала — подмена URL в той же поверхности, не новое окно.
- Картинка сразу после плейлиста. Гид, логотипы, обновления — сбоку.
- Живой поток: HTTP MPEG-TS обязателен, HLS запасной. UDP/RTP из плейлиста не отбрасывать.
- Старт короткий (первый кадр), `bufferSec` — подушка сети, не ожидание перед показом. `decoder` auto/hardware/software реально меняет движок.
- Обрыв потока — тихий повтор того же канала, не выкидывать в меню.
- User-Agent / Referer из настроек. Аудиодорожки на лету.
- EPG — закон окна выше, база на диск, не JSON на сотни МБ в RAM.

## Не забыть при переходе

- Форматы эфира: HTTP MPEG-TS, HLS, UDP/RTP из плейлиста. Звук AAC, AC3/E-AC3, MPEG. Картинка H264 всегда; HEVC только если железо умеет, иначе лестница FHD→HD→SD и сообщение на 2 с.
- Заголовки потока: User-Agent из настроек и Referer/`#EXTVLCOPT` из плейлиста. Дорожки звука и субтитров на лету.
- Xtream: живой `.ts` и запас `.m3u8`. Архив — timeshift как сейчас.
- Обрыв потока — тихий повтор того же канала. Не выкидывать в меню.
- Голос поиска — ключевая фишка: должен работать без нареканий (Windows свой движок, Android — системный). Пульт, гиромышь, Назад/ОК — как в этом файле.
- Каждый тумблер настроек реально меняет поведение, не декорация. Язык в программе ru/en; системный язык только как догадка при первом запуске. Десять языков заранее не пихать.
- Картинка: полный слот, без урезания/смещения/полосок от оболочки. Pad и гид поверх.
- Обновление: тот же Setup, без удаления. Профиль `%AppData%\MirEfir` не чистить. Первый натив читает старые плейлист/EPG/настройки. Экспорт/Импорт резервной копии оставить. Android — та же идея: тихая закачка, кнопки «Обновить» и «Позже», установка, возврат в тот же эфир; «Позже» скрывает кнопки и ставит при следующем запуске; пока не вышли — поставить из «О программе». Профиль в памяти приложения, не сносить. APK сами на GitHub не выкладывать без просьбы.
- Проверка натива: обычный запуск с диска, без Setup и без GitHub на каждый чих. Установщик — когда смотрим «как у человека».
- Запись: спросить память/флешку, писать исходный поток; плюс запись по таймеру из гида. PiP: второе окошко или честное «недоступно». Мультиэкран, архив, облачный код, копировать/вставить, обновление как Cursor — повторить.
- Сценарий один для Windows и Android. Код: Windows первым, Android следом, без урезанной копии. Linux не начинать. `src/` и `electron/` не удалять, пока сценарии не повторены. Setup на GitHub сами не выкладывать.
- Плеер в комплекте приложения (mpv + нужные dll), не скачивать при каждом запуске. Сборка без AVX (обычный x86_64, не v3) — слабый ПК вроде Pentium.
- Системы, на которых должно работать: **Windows 10 и 11, 64-бит** (в том числе старый Win10 и слабый ПК). **Android 7 и новее** (телефон, приставка, ТВ) — как сейчас `minSdk 24`. Не требовать свежайший Win11 или Android 15. Не обещать Windows 7/8/XP и Android 4–6: там уже другая эпоха. Не использовать функции только с самой новой ОС без запасного пути.
- Не плодить чёрные окна и не открывать браузер. В оконном режиме не перекрывать панель задач.
- Экран не гасить во время эфира. Голос локально, без интернета; Whisper не использовать.
- Ещё не сделано в нативе (идеи не забыты): гид в одном файле на диске; голос в новой оболочке; честная запись и PiP; запись по таймеру как в этом файле. Тихий повтор при обрыве и Xtream `.ts` с запасом `.m3u8` — уже в этапе 1 Windows.
