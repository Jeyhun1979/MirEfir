# План перехода: Windows и Android сразу

Один сценарий: `docs/behavior-contract.md`. Меню: `docs/menu-and-settings.md`. Эфир: `docs/native-engine.md`.

Переход длинный, Setup/APK сами не выкладываем. **Этап 0 каркаса есть на обеих сторонах.** Дальше до сдачи делаем **только Windows**: эфир, оболочка, гид, настройки, запись — тестируем и чиним. Android не развиваем, пока Windows не заработает как надо. Сценарий Android тот же, каркас `native/android` не выкидывать.

Linux не делаем. 32-бит Windows пока нет. Старая Chromium/Electron/Capacitor-версия из репозитория убрана при подготовке 1.0.25 (она остаётся в git-истории, тег `v1.0.24`). `D:\MirEfir` не трогаем.

## Завтра утром (этап 0)

1. Создать `native/windows` и `native/android` рядом со старым кодом, ничего из `src/` / `electron/` не вырезать.
2. Windows: пустое окно, выход по Esc, полный экран по Enter, панель задач в оконном режиме видна, браузер не открывается, лишних окон нет. Плеер mpv в комплекте (x86_64 без AVX), пока можно ещё не показывать канал.
3. Android: одна Activity, чёрный экран-заготовка, кнопка Назад выходит по стеку позже, экран не гаснет. Пока без WebView для видео.
4. Отладка: профиль `MirEfir-native`, не `%AppData%\MirEfir`. Не запускать вместе с `electron:dev`.
5. Каркас есть. **Этап 1 Windows готов:** эфир mpv, zap, тихий повтор, Xtream `.ts`. **Этап 2 в работе:** часы, pad, меню, гид-список поверх картинки. Android не трогаем.

## Как устроено

| | Windows | Android |
|---|---|---|
| Папка | `native/windows` | `native/android` |
| Картинка | mpv, один экземпляр, подмена URL | ExoPlayer + SurfaceView, то же |
| Управление | клавиатура, пульт, мышь (ЛКМ=ОК, ПКМ=опции) | пульт, клавиатура, мышь — те же действия |
| Отладка | `MirEfir-native`, не вместе с `electron:dev` | устройство/эмулятор, без релиза на каждый чих |
| Система | Win10/11, 64-бит, без AVX | Android 7+, телефон/приставка/ТВ |
| Для людей (этап 6) | тот же Setup, тот же `%AppData%\MirEfir` | тихая закачка, профиль не сносить |

Общее: настройки и бэкап, облачный код, окно EPG, архив timeshift, запись MP4/MKV, таймер без переключения эфира.

Проверка этапа — локальный запуск. Не Setup, не GitHub.

## Этап 1 — эфир

- После плейлиста сразу картинка. Гид не блокирует.
- Один декодер. Вверх/вниз = подмена URL, не новое окно.
- HTTP MPEG-TS, запас HLS, UDP/RTP из списка не выкидывать.
- Короткий старт, `bufferSec` — подушка.
- Декодер auto / железо / софт реально меняет движок.
- Звук AAC, AC3, MPEG. H264 всегда. HEVC только при железе, иначе FHD→HD→SD и сообщение ~2 с.
- User-Agent и Referer. Дорожки звука на лету.
- Обрыв — тихий повтор того же канала.
- Xtream: живой `.ts`, запас `.m3u8`.
- **Готово:** канал сразу, слабый ПК не чёрный экран.

## Этап 2 — оболочка поверх картинки

Свой вид. Windows — клавиатура обязательна.

- Enter ОК, Esc Назад, стрелки; пульт на Windows и клавиатура на Android — те же действия; мышь: левая = ОК, правая = опции.
- Стек Назад. Pad над картинкой, не сжимает. Часы не прячутся с pad.
- Нет полосок от рамки. Аспект только тумблером.
- Модалка первого плейлиста. Главное меню. Список каналов.
- Телегид поверх эфира.
- **Готово:** листать как сейчас, картинка не уезжает.

## Этап 3 — гид на диск

- Один файл базы. Только каналы плейлиста. Окно архива назад и `epgDays` вперёд.
- Каждые `epgUpdateHours` дописать вперёд, вычистить старое. Без хвостов копий.
- Основной, молчит/хлам — дополнительный, затем остальные. Первый годный файл, без склейки. Все плохие — ошибка, старый файл не затирать.
- Эфир не ждёт гид.
- **Готово:** гид быстрый, память не раздувается.

## Этап 4 — настройки и перенос

Все вкладки из каталога. Каждый тумблер живой.

- Плейлист, копировать/вставить в полях (Windows: клавиатура; Android: пульт).
- Облачный код и Экспорт/Импорт. PIN. Язык ru/en. Внешний вид.
- **Готово:** с текущей версии плейлист и гид на месте, без повторного ввода.

## Этап 5 — голос, запись, архив, остальное

- Голос локально, без Whisper.
- Rec: память или флешка. MP4, запас MKV. Не перекодировать.
- Таймер из гида: пишет поток, экран не трогает.
- Архив: прошедшая передача + Enter/ОК → timeshift; нет — «Архив недоступен»; ±30 с; «Прямой эфир» — в живой.
- PiP честно. Мультиэкран. Поиск. История. Записи.
- **Готово:** меню как в каталоге.

## Этап 6 — обновление и люди

- Windows как Cursor: «Обновить» / «Позже»; «Позже» ставит при следующем запуске или из «О программе». Android та же идея.
- Боевой профиль подхватывает старый. Двух ярлыков не оставлять.
- `src/` и `electron/` убраны (1.0.25). Setup собирает `native/windows/package.bat` (NSIS, `installer/mirefir.nsi`), APK — `native/android` (`assembleRelease`).
- **Готово:** Обновить, без удаления, без повторного ввода ссылок.

## Порядок

Сейчас только Windows (этапы 1–6). Android — после, по тому же сценарию, от уже собранного каркаса.
