# Каталог меню и настроек MirEfir

Снято с кода. При нативном порте повторить один в один. URL плейлиста/EPG в этот файл не писать.

Управление в списках: ↑↓ курсор, ОК вход, Назад шаг назад. На Windows это стрелки, Enter и Esc. На Android — пульт. Клики мышью те же действия.

---

## Главное меню (`uiScreen = menu`)

Панель слева, тёмный фон, клик снаружи закрывает (`closeOverlays`). Курсор сбрасывается на первый пункт при каждом открытии.

| # | Пункт | Подсказка | ОК / клик |
|---|---|---|---|
| 1 | Телевидение | Эфир и категории | `listMode=live`, закрыть все оверлеи, эфир |
| 2 | Телепрограмма | Источники и сдвиг EPG | настройки, вкладка `epg` |
| 3 | Записи | DVR и расписание | экран `recordings` |
| 4 | Мультиэкран | Несколько каналов сразу | экран `multiview` |
| 5 | Поиск | Найти канал или голос | экран `search` |
| 6 | Микрофон | тумблер, не стрелка › | `voiceEnabled` вкл/выкл, меню **не** закрывать. Подпись: «Включён — голос в поиске» / «Выключен» |
| 7 | Плейлисты | M3U и Xtream | настройки, вкладка `playlists` |
| 8 | История | Последние каналы | экран `history` |
| 9 | Настройки | Внешний вид, плеер, пульт | настройки, вкладка `appearance` |
| 10 | Выход | Закрыть приложение | сразу `quitApp`, без диалога |

Клавиши: ↑↓ цикл, ОК — пункт, **влево** — диалог выхода, **вправо или Назад** — `goBack`.

---

## Навигация в настройках

Две колонки: слева вкладки (`pane=nav`), справа содержимое (`pane=content`). Кнопка «‹ Меню» и Назад/влево на вкладках → главное меню. «Закрыть» справа сверху → `closeOverlays` (в эфир).

- На вкладках: ↑↓ смена вкладки, вправо/ОК — в содержимое на первый контрол.
- В содержимом: ↑↓ по кнопкам/полям, ОК/вправо — активировать (клик или фокус в input), влево/Назад — обратно к вкладкам.
- В поле ввода: Назад/влево — снять фокус, не выходить из настроек.

Если `parentalEnabled` и `lockSettings` и PIN ещё не введён: вместо настроек экран «Введите PIN» (Войти / Назад в меню). Успех: `pinUnlock === parentalPin`.

Cycle-кнопки крутят список по кругу одним ОК.

## Вкладка Плейлисты

- Строка «Текущий плейлист» — только показ URL (не редактор).
- Поле URL + кнопка **Обновить плейлист** → `importFromUrl`, пишет `playlists[default]` и `activePlaylistId`. Пока грузится — «Загрузка…».
- Блок Xtream: сервер, логин, пароль. **Добавить Xtream** собирает M3U (`get.php` + `type=m3u_plus`) и вызывает `importFromUrl`. Логин/пароль в git не класть.
- **Интервал обновления** цикл 1 / 3 / 6 / 12 / 24 ч → `playlistUpdateHours`.
- **User-Agent** — текстовое поле, сразу в `settings.userAgent` (уходит в mpv).
- **Папки каналов**: системные «Все каналы», «Избранное», «Недавние» плюс группы плейлиста. Клик строки — скрыть/показать (`hiddenGroups`). Выкл = нет в телегиде и в списке папок.
- **Сортировка каналов** цикл: Как в файле (`playlist`) / По имени (`name`) / По номеру (`number`).

---

## Вкладка Телепрограмма

- Текст: основной, если пустой/хлам — дополнительный, затем остальные по списку. Первый годный XMLTV берём целиком, остальные не качаем. Нет программы у части каналов — нормально. Пустой ответ, HTML и файл без передач в базу не класть. Все плохие — прежняя программа и ошибка.
- У полей ссылок и облачного кода кнопки **Копировать** / **Вставить**. Пульт: Опции/Меню или удержание ОК на поле — Вставить, Копировать, Выделить всё.
- Поле **Основной источник**, поле **Дополнительный** (необязательно). Лишние старые источники — строка + **Удалить**.
- **Загрузить телепрограмму** → `importEpg` включённых URL. Нет основного — ошибка «Укажите основной источник телепрограммы».
- **Сдвиг времени** цикл −12…+12 ч (`epgOffsetHours`).
- **Хранить программу** цикл 1 / 2 / 3 / 5 / 7 / 14 дн. (`epgDays`).
- **Автообновление EPG** тумблер `epgAutoUpdate` (пока приложение открыто).
- **Интервал обновления EPG** цикл 3 / 6 / 12 / 24 ч (`epgUpdateHours`): докачать новый кусок вперёд, выбросить старше окна архива. Не копить.
- **Описания передач** тумблер `showProgramDesc`.

## Вкладка Записи

- **Запись передач** тумблер `recordingsEnabled`. Пишем исходный поток, без потери качества. Файл **MP4**, запас **MKV**. Не врать, если нельзя: нет места, флешка вынута, нет прав, тумблер выключен.
- **Папка записи**: **Выбрать папку** (системный picker) → `recordingPath` + включает записи. Если путь уже есть — кнопка **Спросить снова** сбрасывает путь.
- Rec без папки: спросить **внутренняя память или флешка/диск**, запомнить, писать. Путь уже есть — писать сразу, без вопроса.
- **По таймеру:** в гиде на передаче, которая ещё идёт или будет, — «Записать» (повтор — снять). Список таймеров в экране Записи, кнопка Отмена. В срок пишет живой поток канала в файл, **без переключения** эфира. Один таймер. Сценарий тот же на Windows и Android.

---

## Вкладка Архив

- **Архив (catch-up)** тумблер `archiveEnabled`. Значок ↺ только если в плейлисте канала есть архив.
- **Глубина архива** кнопки 1 / 3 / 5 / 7 / 14 (`archiveDays`); клик также включает архив.
- В гиде: прошедший день + ОК на программе. Нет архива — «Архив недоступен».

## Вкладка Внешний вид

| Опция | Цикл / тумблер |
|---|---|
| Тема | `dark` / `oled` / `graphite` |
| Цвет выделения | синий `blue` / оранжевый `orange` / бирюзовый `teal` |
| Прозрачность панелей | 70 / 80 / 90 / 100 % |

## Вкладка Родительский контроль

- Тумблер `parentalEnabled`.
- **Закрыть настройки PIN-кодом** `lockSettings`.
- Поле нового PIN + **Сохранить** → `parentalPin` (до 8 символов, дефолт `0000`).
- Список групп плейлиста: клик — в/из `lockedGroups`, подпись PIN / открыта.

---

## Вкладка Пульт

«Сменить», затем любая клавиша пишется в `settings.keys`. Пока ждём — «Нажмите кнопку на пульте…». Назад, CH+/CH−, поиск, гид, громкость ± работают сразу без переназначения.

Переназначаемые: Меню, Звук вкл/выкл, Избранное, Полный экран, Телепрограмма, Поиск, Запись, Картинка в картинке, Голосовой поиск, Телегид поверх эфира (←).

Заводы: меню `F2`, mute `m`, избранное пробел, полный экран `Enter`, гид `g`, поиск `s`, запись `r`, PiP `p`, голос `v`, живой гид `ArrowLeft`.

## Вкладка Язык

Цикл Русский `ru` / English `en` (`language`). Голос: ru-RU или en-US.

## Вкладка Данные

Облачный код (настройки, избранное, ссылки; локальный файл M3U не входит):

- **Скопировать код** — сгенерировать, в буфер.
- **Поделиться** — системный share или копия.
- **Применить код** — `importCloudCode` из поля.

Файл:

- **Создать резервную копию** — спросить куда: внутренняя память (папка Backups в профиле) или диск/флешка (выбор папки). Пишет JSON (настройки, плейлист, избранное).
- **Восстановить из резервной копии** — спросить откуда: внутренняя память или файл на носителе.
- **Сброс** — `DEFAULT_SETTINGS` (красный). Плейлист в памяти отдельно не обещать, что сохранится.

## Вкладка О программе

Название MirEfir, одна фраза, номер версии.

Если обновление уже скачано (кнопки в эфире скрыли через «Позже», либо сессия ещё идёт): пункт **Обновить** — поставить из уже скачанного файла, тот же маленький прогресс и возврат в эфир. Нет готового файла — пункта нет, не качать заново с этой вкладки.

## Экран Записи

Сверху таймеры (канал, время, Отмена). Ниже файлы из памяти + файлы в `recordingPath`. Пусто: «Нет записанных передач… REC или R, или таймер в гиде». Клик по файлу — воспроизвести. Назад во время ролика закрывает ролик, ещё раз — в меню.

Кнопки: **Выбрать диск** → настройки `recordings`, **Закрыть** → эфир.

---

## Экран История

Последние 10 каналов. ОК/клик — включить канал и закрыть. Нет в плейлисте — игнор. ↑↓ курсор.

Кнопки: **Очистить историю**, **Меню**, **Закрыть**.

---

## Экран Мультиэкран

До 4 окон, звук только у выбранного. Старт с текущего канала. **+ Добавить окно** / пустой плейсхолдер — поиск по имени или номеру. Крестик на плитке если окон > 1. Назад: закрыть пикер, затем меню. **Закрыть** — эфир. На Windows live основной эфир при мультиэкране ставится на паузу (`pauseForMulti`).

---

## Поиск

Поле + микрофон + до 40 совпадений из видимых каналов. ОК на строке — канал и закрыть. Назад — стоп голоса и `goBack`. Если нет разрешения микрофона: три выбора (разрешить / системные настройки / выключить голос).

---

## Модалка первого плейлиста

Если плейлиста нет — закрыть нельзя. Поля: M3U обязательно, XMLTV необязательно. **Открыть плейлист** по ссылке, **Файл M3U** native/file picker. EPG грузится после плейлиста, ошибка EPG не откатывает каналы. **Отмена** только если это не первый запуск.

---

## Меню канала (долгое ОК ~550 мс)

- Добавить / Удалить из избранного.
- **Переместить** — только в папке избранного: ↑↓ порядок, ОК закрепить, Назад отмена.

---

## Pad в эфире (краткое ОК)

Слева направо: Меню, Гид, Голос, −30с, Пауза, +30с (в прямом эфире не ищет вперёд, подпись «Прямой эфир»), Прямой эфир (переоткрыть канал), Звук (цикл аудиодорожек mpv; без native — честная подсказка), PiP (на native mpv — «пока недоступна»), Rec/Стоп.

Rec без папки — спросить внутренняя память или диск, затем писать. Часы над картинкой, если включены. Полоса под pad только если есть границы архива/длительность.

---

## Диалог выхода

Кнопки Выйти / Отмена. Сам гаснет через 4 с. Назад на диалоге = выход. ОК на Выйти = выход, на Отмена = закрыть.
