# MirEfir

Премиум IPTV-плеер для **Windows** и **Android** (телефоны, планшеты, ТВ-приставки). Свой плейлист, телегид поверх эфира, архив передач, запись, мультиэкран и голосовой поиск. Без рекламы и без чужих каналов внутри.

Начиная с версии **1.0.25** MirEfir — полностью нативное приложение. Браузера (Chromium / Electron / WebView) внутри больше нет: картинку показывает системный видеодвижок, а интерфейс нарисован самим приложением и одинаково работает с клавиатуры, с пульта и пальцем.

Плейлист задаёте только вы: ссылка или файл M3U (в том числе Xtream Codes). Телепрограмму (XMLTV) можно добавить сразу или позже.

## Чем нативная версия лучше

- **Лёгкая и быстрая.** Нет встроенного браузера: приложение занимает в разы меньше памяти и места, запускается за секунды, не греет слабый ПК и приставку.
- **Настоящие видеодвижки.** На Windows картинку показывает **mpv**, на Android — **ExoPlayer (Media3)** с аппаратным декодером. Переключение канала — это подмена адреса потока в уже работающем плеере, а не перезапуск окна.
- **Любые форматы эфира.** Живой MPEG-TS по HTTP, HLS, UDP/RTP; видео H.264, HEVC (H.265), вплоть до 4K, если устройство справляется; звук AAC, AC3/E-AC3, MPEG. Если аппаратный декодер не взялся — автоматически включается программный.
- **Картинка сразу.** Гид, логотипы и обновление плейлиста грузятся сбоку и не задерживают эфир. При обрыве потока канал тихо переподключается сам.
- **Один сценарий везде.** Меню, настройки, клавиши и логика гида одинаковы на Windows и Android.
- **Гид не раздувает память.** Телепрограмма хранится одним файлом на диске, только для каналов вашего плейлиста.

## Что умеет

**Телегид (EPG).** Во время просмотра нажмите «влево»: поверх эфира откроется прозрачный гид (папки → каналы → передачи → дни). Картинка не сжимается и не двигается. Источники XMLTV (`.xml`, `.xml.gz`) можно добавить несколько: основной, дополнительный и запасные; берётся первый годный, мусор на диск не пишется. Гид обновляется сам каждые несколько часов (по умолчанию 6), окно — `7` дней назад и `7` вперёд (настраивается). Если у части каналов программы нет — это нормально.

**Архив передач (Catchup).** Выберите в гиде уже прошедшую передачу — она включится из архива (timeshift). В архиве работают «−30 с» / «+30 с» и полоса времени; кнопка «Прямой эфир» возвращает в живой. Если у канала нет архива, он выключен в настройках или передача старше окна, показывается «Архив недоступен».

**Запись эфира.** Кнопка **Rec** записывает уже играющий поток без перекодирования (`.ts`, после остановки — в `.mp4`, при неудаче в `.mkv`). Куда писать — выбираете сами: внутренняя память или диск/флешка. Запись по таймеру из гида идёт в фоне отдельным потоком и не мешает просмотру; на Android её держит служба с уведомлением, так что запись идёт и при свёрнутом приложении. Все записи — в меню «Записи».

**Мультиэкран до 4 каналов.** Несколько каналов на одном экране, звук у выбранного окна. Кнопка PiP открывает мультиэкран, повторное нажатие возвращает канал на весь кадр.

**Голосовой поиск.** Скажите название канала — плеер его найдёт, «переключи на …» включит сразу. Распознавание **офлайн** (Vosk, без интернета и без Google): модель скачивается один раз при первом включении. На ТВ-приставках работает кнопка микрофона на пульте. Микрофон можно отключить в меню.

**Облачный код переноса.** Избранное, ссылки на плейлист и EPG и основные настройки упаковываются в одну короткую строку. «Настройки → Данные → Скопировать облачный код» (или «Поделиться» в Telegram, WhatsApp, Max, почту), на другом устройстве — «Применить код из буфера». PIN, путь записи и горячие клавиши в код не попадают. Там же — **резервная копия** профиля в файл и восстановление из него.

**Остальное.** Поиск и история каналов, избранное, группы и сортировка, родительский контроль с PIN, русский и английский язык, смена дорожки звука и субтитров, логотипы каналов, внешний плеер по желанию, часы поверх эфира, темы и размеры.

## Управление

Одно и то же на всех платформах: на Windows — клавиатура, на Android — пульт или экран.

| Действие | Windows | Пульт / касание |
|---|---|---|
| ОК, выбор | Enter | ОК, тап |
| Назад | Esc | Назад |
| Следующий / предыдущий канал | ↓ / ↑ (или PgDn / PgUp) | ↓ / ↑, свайп вверх/вниз |
| Телегид поверх эфира | ← | ←, свайп от левого края |
| Прошлый канал | → | →, свайп от правого края |
| Нижняя панель (меню, гид, голос, −30 с, пауза, +30 с, прямой эфир, звук, PiP, Rec) | короткий Enter | короткий ОК, тап |
| Меню канала (избранное, перенос) | долгий Enter | долгий ОК, долгий тап |

Дополнительно на Windows: `F2` меню, `M` звук вкл/выкл, `G` гид, `S` поиск, `R` запись, `P` мультиэкран, `V` голос, `A` дорожка звука, `F11` полный экран, `Пробел` избранное. Клавиши можно переназначить в «Настройки → Пульт». В полях ссылок и кодов есть «Вставить» и «Копировать» — удобно и с пульта.

## Скачать и установить

Готовые файлы — в [Releases](https://github.com/Jeyhun1979/MirEfir/releases).

| Платформа | Файл | Требования |
|---|---|---|
| Windows | `MirEfir-Setup-1.0.25.exe` | Windows 10 или 11, 64-бит. Проигрыватель mpv уже внутри, ничего докачивать не нужно (без AVX — запускается и на старых процессорах). |
| Android, ТВ | `MirEfir-1.0.25.apk` | Android 7.0+; телефон, планшет, Android TV и приставки. |

Windows может показать предупреждение о неизвестном издателе: «Подробнее» → «Выполнить в любом случае». На Android разрешите установку из неизвестных источников.

Первый запуск: укажите ссылку на M3U или выберите файл, по желанию добавьте XMLTV. Каналы появятся сразу после загрузки плейлиста.

## Обновление с версии 1.0.24

Ничего удалять и настраивать заново не нужно: **плейлисты, телепрограмма, избранное, история и настройки сохраняются**.

**Windows.** Если у вас стоит MirEfir 1.0.24, он сам предложит обновиться: нажмите «Обновить» — Setup установится тихо, а новая версия откроется на том же месте. Можно и вручную: запустите `MirEfir-Setup-1.0.25.exe`. Установщик находит папку прежней установки, заменяет в ней файлы программы и обновляет ту же запись в «Программах и компонентах»; ярлыки остаются. Папка данных `%AppData%\MirEfir` **не удаляется ни при обновлении, ни при удалении программы**: при первом запуске нативная версия подхватывает из неё плейлисты, источники EPG и настройки. Старые служебные папки браузера (`Cache`, `GPUCache`, `Local Storage` и т. п.) больше не нужны, их можно удалить вручную — на работу это не влияет.

**Android.** MirEfir 1.0.24 предложит скачать `MirEfir-1.0.25.apk`; также можно просто открыть APK. Пакет (`com.mirefir.app`) и подпись те же, поэтому установка идёт поверх старой, без удаления. При первом запуске плейлисты и настройки переносятся из прежней версии.

**Дальше** обновления приходят так же: приложение само скачивает новую версию в фоне, слева внизу появляются кнопки «Обновить» и «Позже». «Позже» прячет кнопки и оставляет файл: поставить можно в «Настройки → О программе» или при следующем запуске.

## Сборка из исходников

Исходники лежат в `native/windows` (C) и `native/android` (Java). Подробное описание поведения — в `docs/`.

### Windows

Нужен Windows 10/11 x64 с интернетом (при первой сборке скачиваются компилятор и плеер).

```bat
cd native\windows
run.bat        :: сборка и запуск для отладки (профиль %AppData%\MirEfir-native)
build.bat      :: только сборка bin\mirefir.exe
package.bat    :: сборка и Setup: dist\MirEfir-Setup-<версия>.exe
```

- Компилятор — портативный **Zig 0.13.0** (`zig cc`): `build.bat` скачивает его сам в `native\windows\tools`.
- Плеер **mpv** (x86_64, без AVX) и `vulkan-1.dll` кладёт в `vendor\mpv` скрипт `fetch-mpv.ps1` (вызывается автоматически).
- Setup собирает **NSIS 3** (`installer\mirefir.nsi`): `makensis` берётся из `PATH`, из `C:\Program Files (x86)\NSIS` или из кэша electron-builder. Версия берётся из `MIREFIR_VERSION` в `src\app.h`.
- Отладка идёт в отдельном профиле `MirEfir-native` (переменная `MIREFIR_PROFILE=native` ставится в `run.bat`); обычный запуск работает с `%AppData%\MirEfir`.

### Android

Нужны JDK 17+ и Android SDK (platform 35). Gradle скачивается через `gradlew`.

```bat
cd native\android
gradlew.bat assembleDebug      :: отладочный APK
gradlew.bat assembleRelease    :: релизный app\build\outputs\apk\release\MirEfir-<версия>.apk
```

Релизная сборка подписывается ключом из `native/android/app/mirefir-release.jks` и паролей в `native/android/keystore.properties`. Оба файла **не хранятся в git** — нужен тот же ключ, что у 1.0.24, иначе APK не встанет поверх установленного. Без этих файлов `assembleRelease` остановится с понятной ошибкой.

### Версия и имена файлов релиза

Автообновление ищет в последнем релизе на GitHub: на Windows — файл `.exe` с `setup` в имени, на Android — файл `.apk`. Поэтому в релизе должны быть ровно `MirEfir-Setup-<версия>.exe` и `MirEfir-<версия>.apk`, а тег — `v<версия>`. Версию меняют в трёх местах: `native/windows/src/app.h`, `native/android/app/build.gradle` (`versionName`, `versionCode`) и `native/android/app/src/main/java/com/mirefir/nativedev/App.java`.
