# MirEfir

Премиум IPTV-плеер для Windows, Linux и Android TV. Свой плейлист, живой гид поверх эфира, пульт и голос — без рекламы и без чужих каналов внутри.

Плейлист задаёте только вы: ссылка или файл M3U. Телепрограмму (XMLTV) можно добавить сразу или позже.

## Чем отличается

- **Голосовое переключение.** Скажите название канала — плеер найдёт и включит. На пульте та же кнопка, что и поиск.
- **Один код — все устройства.** Избранное, ссылки на плейлисты и телепрограмму упаковываются в одну строку. Скопировали, отправили в мессенджер, вставили на телевизоре или ПК — настройки применятся сами.
- **Телегид поверх эфира.** Во время просмотра ← открывает прозрачную программу, ещё раз ← — ваши категории, → — сетка передач и дни. Картинка не сжимается.
- **Запись туда, куда удобно.** Спрашивает: внутренняя папка или диск / флешка. Не пишет «втихую» только внутрь приложения.
- **Мультиэкран и картинка в картинке.** Несколько каналов сразу или мини-окно поверх других программ.
- **Пульт и Android TV.** D-pad, Назад, CH+/−, гиромышь. Управление рассчитано на диван, не только на мышь.
- **Архив (catch-up)** у каналов, где это есть в плейлисте.
- **Свои обновления.** Новая версия предложит обновиться или пропустить.

## Скачать

Готовые файлы — в [Releases](https://github.com/Jeyhun1979/MirEfir/releases).

| Платформа | Файл | Как запускать |
|---|---|---|
| Windows | `MirEfir-*-windows.exe` | Скачать и запустить. Windows может показать предупреждение неизвестного издателя: «Подробнее» → «Выполнить в любом случае». |
| Windows | `MirEfir-Setup-*.exe` | Обычная установка в папку, если нужен ярлык в меню. |
| Linux | `MirEfir-*-linux-x64.tar.gz` | Распаковать архив и запустить `MirEfir`. |
| Android / ТВ | `MirEfir-*.apk` | Установить APK. На телефоне и приставке разрешите установку из неизвестных источников. |
| macOS | — | Сборка только с Mac, в этом релизе нет. |

Плеер сам не ставит каналы. При первом запуске укажите **свой** M3U (ссылка или файл). У каждого пользователя свой плейлист.

## Первый запуск

1. Скачайте файл под свою систему и откройте его.
2. Укажите ссылку на M3U или выберите файл.
3. По желанию добавьте XMLTV (`.xml` / `.xml.gz`).
4. Каналы появятся сразу после загрузки плейлиста.

Чтобы перенести избранное и плейлист на другой телевизор или ПК: **Меню → Настройки → Данные → Облачный код** — скопировать или «Поделиться», на втором устройстве вставить тот же код.
